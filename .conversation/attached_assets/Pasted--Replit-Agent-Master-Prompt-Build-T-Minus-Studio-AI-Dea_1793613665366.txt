# Replit Agent Master Prompt: Build "T-Minus Studio" — AI Deadline Planner & Countdown Lock Screen Generator

Act as a senior full-stack developer, UI/UX designer, and AI application architect. Build a complete, production-quality web application called **T-Minus Studio**.

The application is based on the challenge "Your Deadline, Your Design: Create a Countdown Lock Screen."

The goal is to help users choose an upcoming deadline, use AI to break it into manageable milestones, design a personalized countdown lock screen, track progress, and configure reminders.

Do not build just a static landing page or a simple countdown timer. Build a complete, interactive application with a premium interface, functional workflows, image export, and persistent user data.

---

# 1. Technology Stack

Use the following technologies:

- Frontend: React.js with TypeScript.
- Build tool: Vite.
- Styling: Tailwind CSS.
- UI components: shadcn/ui where appropriate.
- Icons: Lucide React.
- Backend: Node.js with Express.
- AI integration: Google's official Gemini API using the current supported Google Gen AI SDK.
- Image export: HTML-to-image or an equivalent reliable browser-side rendering library.
- Date handling: date-fns.
- Storage: LocalStorage for initial persistence. Keep the data layer modular so it can be upgraded to a database later.

Use a clean, modular project structure.

Keep API keys on the server, never in frontend code. Read the Gemini key from Replit Secrets using `GEMINI_API_KEY`.

If the key is missing, the application must still work with a useful manual planning mode.

Do not fake AI responses or claim that an AI operation succeeded when it did not.

# 5. Deadline Creation Wizard

When the user clicks "Create a Countdown", open a multi-step wizard.

Make it feel like an intuitive onboarding experience rather than a long form.

### Step 1: Define Your Goal

Fields:

- Project or goal name.
- Goal description.
- Deadline date.
- Deadline time.
- Time zone.

Example:

Project: Complete Portfolio Website

Description: Finish and publish my professional portfolio.

Deadline: User selects a date and time.

Automatically detect the user's local time zone and allow changing it.

Validate all fields.

Do not allow a past deadline for a new countdown.

### Step 2: Understand Your Schedule

Ask the user three short questions:

1. How many hours can you dedicate to this goal each day?
2. Which days are you unavailable?
3. Have you already started working on this goal? What remains to be completed?

Provide editable answers.

### Step 3: Generate a Plan

Add a prominent button:

"Generate My Milestone Plan"

Use Gemini to analyze the goal, deadline, available time, and remaining tasks.

Ask Gemini to work backward from the deadline and create practical milestones.

The generated schedule should include:

- T-14 days.
- T-7 days.
- T-3 days.
- T-1 day.
- Deadline day.

Adapt these milestones when the deadline is less than 14 days away. Never create milestones dated before the current date.

Every milestone should contain:

- T-minus label.
- Calendar date.
- Short milestone title.
- Description.
- Suggested tasks.
- Priority.
- Checkbox for completion.

Keep milestone titles concise, preferably under five words.

The AI should generate realistic milestones rather than generic repeated descriptions.

Example:

| Timeline | Milestone | Tasks |
|---|---|---|
| T-14 | Complete Research | Finalize scope and references |
| T-7 | Finish Core Work | Complete main deliverables |
| T-3 | Review Everything | Test and fix remaining issues |
| T-1 | Final Preparation | Final checks and submission |
| T-0 | Meet The Deadline | Submit final deliverable |

These are illustrative examples. Generate milestones based on the actual user goal.

### Important AI behavior

- Ask the user for missing information.
- Provide concise, actionable suggestions.
- Avoid unrealistic schedules.
- Allow manual editing of every milestone.
- Allow users to regenerate the plan.
- Display a useful error and offer manual planning if Gemini is unavailable.
- Do not invent tasks based on information the user has not provided.
